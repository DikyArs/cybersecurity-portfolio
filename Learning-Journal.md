# 📓 Jurnal Pembelajaran Cybersecurity

Selamat datang di jurnal pribadi saya. Di sini saya mencatat perkembangan keterampilan, pola pikir, dan pelajaran berharga sepanjang membangun portofolio ini.  
Tujuan saya: membuktikan bahwa belajar cybersecurity bisa dilakukan secara otodidak, konsisten, dan terdokumentasi dengan baik.

---

## 🗓️ Timeline Pembelajaran

### Day 0 – Pondasi & Repo
- **Skill:** Inisialisasi Git, struktur folder portofolio.
- **Refleksi:** Memulai adalah langkah tersulit. Sekarang saya punya kerangka.

### Day 1 – Markdown & Struktur
- **Skill:** Markdown dasar, pembuatan folder, README awal.
- **Tantangan:** Membiasakan diri dengan path relatif untuk gambar.

### Day 2 – Lab Pribadi (Debian + Metasploitable 2)
- **Skill:** Virtualisasi, jaringan host-only, dokumentasi setup.
- **Pelajaran:** Isolasi lingkungan sangat penting untuk keamanan.

### Day 3 – Eksploitasi vsftpd Backdoor
- **Skill:** Nmap enumeration, eksploitasi manual, reverse shell.
- **Highlight:** Berhasil mendapatkan root tanpa Metasploit, hanya dengan `nc`.

### Day 4 – TryHackMe: RootMe
- **Skill:** Web enumeration (gobuster), bypass upload filter, SUID privilege escalation.
- **Pelajaran:** Filter ekstensi harus whitelist, bukan blacklist.

### Day 5 – Proyek Mandiri: Port Scanner Python
- **Skill:** Pemrograman socket Python, tool building.
- **Refleksi:** Memahami cara alat bekerja itu lebih penting daripada sekadar menjalankannya.

### Day 6 – Analisis Malware Statis
- **Skill:** String analysis, hash lookup, VirusTotal, penulisan laporan IOC.
- **Pelajaran:** Bahkan tanpa menjalankan malware, banyak informasi bisa digali.

### Day 7 – Jurnal & Finalisasi Portofolio
- **Skill:** Dokumentasi reflektif, penyempurnaan README.
- **Pencapaian:** Portofolio ready.
